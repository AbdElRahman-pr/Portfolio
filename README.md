# Personal Portfolio Website

A modern and responsive personal portfolio website built using HTML5 and CSS3. It showcases my background, technical skills, software projects, certificates, and contact information.

## Features

* Modern dark user interface
* Fully responsive design
* About Me section
* Technical Skills section
* Projects showcase
* Certificates section
* Contact and social media links
* Smooth scrolling
* Hover effects and CSS transitions
* Print-friendly styling

## Built With

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries
* CSS Variables
* Transitions and Transform effects

## Project Structure

```text
portfolio/
├── index.html
├── css/

    └── project-images/
```

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No installation or external dependencies are required.
